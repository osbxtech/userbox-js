# Security policy

## Supported versions

Only the latest alpha of each package receives fixes:

| Package | Supported |
|---------|-----------|
| `@userbox/react` | latest `alpha` |
| `@userbox/node` | latest `alpha` |

## Reporting a vulnerability

Please report privately, never in a public issue or pull request:

- GitHub private vulnerability reporting:
  https://github.com/osbxtech/userbox-js/security/advisories/new
- or email **security@osbxtech.nl**.

Include the package, the version, and a minimal reproduction. Do not include
real credentials.

We aim to acknowledge a report within 3 working days and to agree a fix and
disclosure timeline with you. There is no bug bounty.

Each package keeps a short threat-model summary in its own `SECURITY.md`
([react](react/SECURITY.md), [node](node/SECURITY.md)).
